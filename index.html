Open source

Jackson Moral Governance Layer (JMGL)

JMGL checks every AI action against written ethical laws before it reaches people, and shows its work.

JMGL is a free, open-source policy engine. Before an AI reply or action goes out, JMGL checks it against written laws and returns a decision with the rule and the reason. Every decision is logged, and when the gate is unsure, it holds the action for a person to review instead of letting it through.

View JMGL on GitHub

Our honest numbers

On synthetic tests, adding a small local AI judge to the rules gave these results:

Harmful requests let through
Dropped from 65.7% to 27.3%
Harmless requests wrongly flagged
Rose to 18.2%

These are early results on test data we generated ourselves. There has been no independent testing yet. JMGL still misses harmful requests and still flags some harmless ones, which is why we publish the numbers and keep improving it.
